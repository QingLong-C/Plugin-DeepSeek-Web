# 错误分类与运行时恢复

维护文档保存规则，运行时由插件恢复层执行；skill 或后台定时守卫不能代替每次响应的校验。普通生成、工具参数、DSML 与模型纠正共用解析和提交入口，不按每次坏字符串建立新重试分支。

| 类别 | 自动处理 | 必须保留的边界 |
| --- | --- | --- |
| 完整字符串的编码、围栏、根外装饰 | 等价编码或有限移除 | 不改变解码后的值，不删正文 |
| 缺逗号、冒号、已有容器的结束符 | 有界语法搜索，比较最低成本候选 | 歧义、缺值、重复键、坏转义或预算耗尽拒绝 |
| 完整对象/数组根之后多出的 `}`、`]` | 在 8 次结构编辑预算内移除任意组合 | 只在根完整之后；内部错配、额外根或值不删除 |
| 明确工具参数错层 | 按当前原始工具声明无损归位 | 不猜字段、补默认、强转或覆盖冲突 |
| 仍不合格的协议/参数/最终回答 | 共享、有限、按阶段进展判断的模型纠正 | 工具不能改成未验证总结；已展示 final 不能改成工具 |
| 模型缺失、抄错或沿用旧请求编号 | 编号不属于输出内容契约；插件按已核验官网响应绑定 | 不额外生成；原生 ID 来自当前操作，正文和原始 schema 不变 |
| 官网限流 | 明确未接受时排队、冷却后续当前生成 | 接受不明或已有输出不盲重发；不重启原任务 |
| 断流或历史不一致 | 同响应核实、已有续传与结算规则 | 不用格式重试掩盖身份或分支错误 |
| 登录、过滤、官网身份、策略、工具执行失败 | 显示实际原因并按对应错误停止或处理 | 不伪造成功，不重放已完成工具 |

只有全部调用通过原始 schema、身份、目录与会话策略，才整批交给原生执行端。恢复器只处理数据；执行端继续做自己的校验，已确认结果继续作为下一步上下文。

## 持久化闭环（v1.1.0）

遇到支持分类的格式错误，插件先记为 `pending`，然后按原有准入条件自动修复或请求模型纠正；整批通过当前参数、身份、策略和纠正结果校验后才记为 `resolved`。仍不合格则保持待解决，曾经修好后再次失败也会重新变为待解决；已有成功处理记录保留。这里的 resolved 只证明格式校验通过，工具执行结果仍由 DSH 原生事件决定。

记录存放在插件数据目录的 `recovery-memory/<scope>.json`，默认位于 `~/.dsh-tokenfree/`。scope 由当前工具目录及输出策略生成；条目保存错误阶段/码、次数、时间、固定处理方式标识和 operation ID，不保存正文、参数或命令。operation ID 用于关联本地已有请求日志，原始日志仍按现有设置私有保存，不推送到 GitHub。

后续相同契约的生成及纠正请求可提前带上曾通过校验的格式提示；确定性本地恢复仍对所有候选生效。复用的是程序内置的格式处理规则与固定提示，不是上次的答案、命令、任意模型生成的脚本或运行时自动安装的补丁。参数、身份及执行检查不因记录而跳过；输入预算不足时省略提示或完整坏候选，不截断权威上下文，不增加纠正额度。

记录使用私有权限、原子写入及跨进程锁。记录不可读或损坏时保留原文件，诊断日志写 `model.format-memory / unavailable`，主恢复链继续遵守原有校验；不能因记忆文件出问题直接派发。pending、resolved、reuse 也使用同一诊断事件。真正的新协议或缺失信息仍可能需要人工修改与回归，记录会帮助定位，不能保证任意新错误自动学会或下次一定一遍通过。

## 增加或调整恢复规则

1. 保存原始完整候选与官网终态，绑定同一 turn、step、operation；先判断属于哪一类，不根据任务标题或题材推断。
2. 先用旧版测试复现失败，再改共享入口。测试同时检查允许恢复、必须拒绝、参数值不变、恢复预算和无额外模型生成。
3. 覆盖对象和数组、嵌套结构及组合损坏；执行层用受控无副作用工具验证一次派发/一次结果，现场命令只做离线解析重放。
4. 完整检查通过后安装发行包，验证设置、账号与其他插件，再同步源码、版本说明和维护 skill。有限测试不代表已穷举任意模型输出。
5. 同一 checkout 的 clean/build、依赖 lib 的测试与打包顺序执行；需要并行时使用隔离的构建目录，避免清理产物导致模块缺失。中断后核对进程和原始退出码，未完成的记录不能作为通过证据。

相关测试见 `tests/grammar-recovery.test.mjs`、`tests/tool-policy.test.mjs`；解析实现在 `src/core/json.ts`、`src/core/codec.ts`，纠正与结算在 `src/core/session.ts`，交付校验在 `src/dsh/adapter.ts`。
